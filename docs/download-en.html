Version 1.1.0 notes

The workshop measurement recorded a 4,467 ms window-ready time and 174 MB idle working set. These exceed internal targets of 2,500 ms and 120 MB; they are measurements on that machine, not universal system requirements.

Version 1.1.0 adds oxygen, temperature and pH effects, lag and decay, a configured CFU/mL estimate, and automatic batch termination. See the Portuguese model notes and sample trajectory.

Requirements and platforms

  • Windows 10 or later, 64-bit. Linux and macOS packages are not available; no release date has been announced.
  • The MSI and ZIP include the Java runtime; installing Java separately is not required.
  • 4 GB of RAM is recommended for Windows and the application together. This is a practical recommendation, not a universal measured minimum.

Windows SmartScreen

The release is not code-signed, so Windows may show “Windows protected your PC” or an unknown-publisher warning. Keep SmartScreen enabled.

  1. Download only from the GitHub release linked above.
  2. Check that the file size and SHA-256 match the values on the Portuguese download page.
  3. If SmartScreen blocks the verified installer, select More info, confirm the displayed file name, then select Run anyway. If that option is absent or the publisher/file name differs, cancel and contact support.

Local data and license

Batch history is stored locally in SQLite under %APPDATA%\CaraCore\BioReator40; exported CSV files are stored under %LOCALAPPDATA%\CaraCore\BioReator40\laudos. The simulator does not upload batch history to a cloud service.
