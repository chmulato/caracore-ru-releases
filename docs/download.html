Checksums
Baixar SHA256SUMS.txt da versão 1.1.1. O mesmo arquivo acompanha os artefatos da release.

  • Community: Bradyrhizobium japonicum, batelada, gráficos ao vivo, histórico em AppData e CSV. É a edição do pacote local.
  • Edição paga planejada: prevista para 2027. O escopo e as condições comerciais ainda não estão publicados.
  • Tanque 1.1.1: 50 L a 10.000 L, fração de trabalho de 70% a 80%. Crescimento por Monod com fatores configurados de oxigênio, temperatura, pH e fase lag; o perfil também aplica decaimento celular.

O guia de batelada e de leitura da tela está no manual do operador. A carga de 100 L, com biomassa, substrato e oxigênio ao longo das horas, está no exemplo de batelada. Dúvidas pelo canal de feedback, sem SLA.

Requisitos e plataformas

  • Windows 10 ou posterior, 64 bits.
  • 4 GB de RAM são recomendados para o Windows e o simulador juntos; não há mínimo universal medido/documentado.
  • O pacote inclui o runtime Java 25: não é necessário instalar Java separadamente.
  • Não há instalador Linux ou macOS nem data de lançamento anunciada para essas plataformas.
  • Interface e documentação técnica estão em português. A página de download em inglês cobre instalação e requisitos; ainda não há versão inglesa do aplicativo.

Aviso do Windows SmartScreen

O MSI e o ZIP não têm assinatura digital; por isso, o Windows pode avisar que o publicador é desconhecido. Mantenha o SmartScreen ligado.

  1. Baixe somente pela release oficial ligada nesta página.
  2. Confira tamanho e SHA-256 acima. No PowerShell, use Get-FileHash .\BioReator40-1.1.1.msi -Algorithm SHA256 (ou troque pelo nome do ZIP) e compare o hash completo.
  3. Se o aviso “O Windows protegeu o computador” aparecer, selecione Mais informações, confira o nome do arquivo e só então Executar assim mesmo, desde que o SHA-256 corresponda.
  4. Se o nome não corresponder, o hash divergir ou a opção não aparecer, cancele a execução e contate o suporte. Não desative o SmartScreen.

O que o histórico guarda

O histórico SQLite fica em %APPDATA%\CaraCore\BioReator40. Os arquivos CSV exportados ficam em %LOCALAPPDATA%\CaraCore\BioReator40\laudos. O simulador não envia os lotes à nuvem.
